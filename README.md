# エラーログが大量に出てくるだけの暇つぶしのやつ (Error Log Stream)

エラーログが大量に出てくるだけの暇つぶしのやつです。

Webブラウザまたはターミナル（CLI）上で、深刻そうなエラーログ、カーネルパニック、スタックトレース、サイバー攻撃アラート、AIの暴走ログなどが怒涛の勢いで流れ続けます。

---

## 💡 こんな時におすすめ

- **退屈なオンライン会議中**: 画面共有の端っこに映したり、全画面で眺めながら険しい顔をすることで「今めちゃくちゃ深刻なインシデント対応をしてる人」を演出できます。
- **ハッカー・エンジニア気分を味わいたい時**: キーボード連打モードで映画のハッカーのようにエラーを画面一杯に撒き散らせます。
- **純粋な暇つぶし**: 謎のエラーメッセージや開発者の言い訳をぼーっと眺めて癒やされたい時に。

---

## 🚀 クイックスタート

### 1. Webブラウザで遊ぶ

```bash
# サーバー起動 (外部パッケージ不要・Node.js標準機能のみで動作)
npm start
# または
node server.js
```

ブラウザで `http://localhost:3000` を開きます。

#### 主なWeb機能
- **リアルタイム高速ストリーム**: 1〜100行/秒のスピード調節、一時停止、1行ステップ実行
- **🚨 緊急復旧試行ボタン**: 押すとシステムが直りかける……と思いきや、事態が10倍悪化して大爆発します
- **💥 自爆シーケンス**: カウントダウンと共に画面が激しくグリッチし、システムが自壊します
- **⌨️ ハッカー連打モード**: キーボードをカタカタ叩くたびにエラーが爆速で噴出します
- **🔊 サウンド機能**: Web Audio API によるシンセサイザー警報音・ビープ音
- **🤖 言い訳ジェネレーター**: 気になるエラー行をクリックすると、開発者のシュールな言い訳が表示されます
- **CRT走査線 & 全画面モード**: 昔の監視室端末のようなレトロモニター風UI

---

### 2. ターミナル (CLI) で遊ぶ

ターミナル上でもANSIカラー付きでド派手にエラーを流せます。

```bash
# デフォルト（カオスモード）で実行
npm run cli

# または直接実行
node cli.js

# オプション指定の例
node cli.js --scenario kernel --interval 20 --lines 100
```

#### CLIオプション
| オプション | 短縮 | 説明 | デフォルト |
|---|---|---|---|
| `--scenario` | `-s` | シナリオID (`all`, `cloud`, `kernel`, `scifi`, `gamedev`, `developer`) | `all` |
| `--interval` | `-i` | ログ出力間隔 (ミリ秒) | `50` |
| `--lines` | `-n` | 指定した行数を出力して終了 | 無制限 (Ctrl+Cで終了) |
| `--help` | `-h` | ヘルプ表示 | - |

## 🎭 収録シナリオ

1. **🌐 Web/クラウドインフラ大崩壊 (`cloud`)**: Kubernetes CrashLoopBackOff、PostgreSQLコネクション枯渇、Redis OOM、React Hydrationエラーなど。
2. **💻 Linuxカーネルパニック & C/C++暴走 (`kernel`)**: Segmentation fault、OOM Killer、メモリ二重解放、スタック破壊など。
3. **🚀 SF宇宙船AI暴走 & 臨界事故 (`scifi`)**: HAL 9000の反乱、反物質リアクター臨界、隔壁閉鎖、自爆シーケンスなど。
4. **👾 ゲーム開発・物理演算の怪奇現象 (`gamedev`)**: 荒ぶるラグドール、NaNベクトルの彼方への消失、紫と黒の市松模様テクスチャなど。
5. **☕ プログラマー日常の絶望 & シュール (`developer`)**: git force pushの悲劇、深夜4時のコミット、謎のCSS z-index戦争など。
6. **🎲 オールスター・カオスモード (`all`)**: 上記の全シナリオがごちゃ混ぜで発生する地球滅亡モード。

## 🛠️ API エンドポイント

開発者向けにHTTPエンドポイントも提供しています。

- `GET /api/scenarios` : シナリオ一覧の取得
- `GET /api/log?scenario=all&count=5` : JSON形式でエラーログを取得
- `GET /api/stream?scenario=all&interval=100` : Server-Sent Events (SSE) によるリアルタイムログストリーム
